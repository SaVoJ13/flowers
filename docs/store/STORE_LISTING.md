## 1. Метадані

### Назва (≤ 30 символів)
`Flowers: Догляд за рослинами` (28)

### Короткий опис (≤ 80 символів)
`М'які нагадування, поради з догляду й картка рослини від ШІ.` (60)

### Повний опис (≤ 4000 символів)
```
Губите кімнатні рослини через надмірний полив? Flowers допомагає доглядати без стресу: нагадує не «полий», а «перевір ґрунт», і підказує, що робити далі.

🌱 ЩО ВМІЄ FLOWERS

1. М'ЯКІ НАГАДУВАННЯ
Щоденне нагадування перевірити ґрунт і стан рослин. Земля ще волога? Відкладіть перевірку на 1–3 дні одним дотиком. Жодних штрафів і червоних позначок.

2. ПОДИ ЗНАНЬ
Короткі підказки на картці рослини: як перевірити вологість пальцем, де поставити вазон, яка помилка найчастіша саме для цього виду.

3. ДОВІДНИК РОСЛИН
Вбудований каталог із 20 популярних кімнатних рослин (заміокулькас, монстера, спатифілум, сансевієрія, фікуси та інші), працює без інтернету.

4. КАРТКА РОСЛИНИ ВІД ШІ
Немає вашої рослини в довіднику? Введіть її назву, і ШІ підготує картку догляду. Потрібен інтернет. Це порада, а не гарантія: перевіряйте її. Для карток від ШІ застосунок не стверджує, що рослина безпечна для тварин чи дітей. Якщо відповідь неправильна чи небезпечна, натисніть «Поскаржитися на відповідь ШІ».

5. ОФЛАЙН-ЧЕКЛИСТ СТАНУ
Пожовтіло листя чи поникли пагони? Пройдіть короткий огляд (листя, стебло, ґрунт, шкідники): застосунок зіставить симптоми з журналом поливу й запропонує, що перевірити.

6. ЖУРНАЛ ДОГЛЯДУ
Фіксуйте поливи, підживлення та інші події для кожної рослини.

🔒 ПРИВАТНІСТЬ
• Без реєстрації й облікових записів.
• Рослини та журнал зберігаються лише на вашому телефоні.
• Інтернет використовується лише для ШІ-картки (назва рослини надсилається до Google; на безкоштовному рівні Google може використовувати запити для покращення своїх продуктів) і для скарги на відповідь ШІ.
• Без реклами й аналітики. Не вводьте особисті дані в назву рослини.
• Для користувачів 18+.

Застосунок не замінює ветеринара чи лікаря. Якщо тварина або дитина з'їла частину рослини, негайно зверніться до ветеринара або лікаря.
```
