## 1. Загальна інформаційна архітектура та навігація

Застосунок використовує класичну нижню панель навігації (**Bottom Navigation Bar**) із трьома основними розділами та швидким доступом до довідника/налаштувань:

```
                  ┌─────────────────────────────────────────┐
                  │          Flowers (Головне вікно)        │
                  └────────────────────┬────────────────────┘
                                       │
     ┌─────────────────────────────────┼─────────────────────────────────┐
     ▼                                 ▼                                 ▼
[1. Сьогодні]                   [2. Мої рослини]                 [3. Довідник]
- Поточні перевірки             - Список вазонів                 - Каталог видів
- Прострочені завдання          - Кнопка «+ Додати»              - Поди для початківців
- Швидкі дії (Виконано/Відкласти) - Фільтр за кімнатами          - Пошук за назвою
     │                                 │
     ▼                                 ▼
[Діагностика стану]             [Картка рослини]
- Покроковий майстер            - Поди-підказки виду
- Кореляція з журналом          - Графік перевірок
- План порятунку                - Журнал та фотодинаміка
                                       │
                                       ▼
                                [Налаштування]
                                - Сповіщення, тема, експорт
```

## 2. Детальні сценарії користувача (User Flows)

### Flow 1: Швидке додавання першої рослини (< 60 секунд)
**Мета:** Дати користувачеві миттєвий результат без реєстрації, форм авторизації чи складних анкет.

```
[Старт застосунку] ──> [Порожній екран «Сьогодні» / «Мої рослини»]
                              │
                              ▼ (Клік «+ Додати рослину»)
                 [Крок 1: Назва та Вид рослини]
                 - Введення власної назви (напр. «Монстера біля вікна»)
                 - Пошук/вибір виду з каталогу (або «Свій вид / Не знаю»)
                              │
                              ▼
                 [Крок 2: Розташування та Освітлення]
                 - Вибір кімнати (Вітальня, Спальня, Кухня, Кабінет тощо)
                 - Рівень світла (Яскраве розсіяне, Тінь, Пряме сонце)
                              │
                              ▼
                 [Крок 3: Фото та Старт (Необов'язково)]
                 - Додати перше фото (з камери або галереї) або пропустити
                 - Перемикач: «Увімкнути м'які нагадування» (за замовчуванням: Так)
                              │
                              ▼
               [Екран рослини з відкритими подами-підказками!]
               Користувач ОДРАЗУ бачить:
               1) Як тактильно перевірити ґрунт саме цього виду;
               2) Скільки світла потрібно;
               3) Головну помилку новачка.
```

### Flow 2: Щоденний догляд та обробка «м'якого нагадування»
**Мета:** Усунути почуття провини та попередити перелив рослин.

```

          │
          ▼ (Клік по сповіщенню або відкриття вкладки «Сьогодні»)
[Картка завдання на екрані «Сьогодні»]
«Спатифілум (Вітальня) — Перевірка ґрунту»
Підказка: «Занурте палець на 2 см: поливайте, лише якщо верхній шар сухий»
          │
          ├─────────────────────────┬─────────────────────────┬─────────────────────────┐
          ▼                         ▼                         ▼                         ▼
   [«Виконано»]             [«Відкласти»]               [«Пропустити»]          [«Є проблема»]
   - Ґрунт сухий,           - Ґрунт ще вологий!        - Полив зараз             - Листя пожовтіло

### Flow 3: Інтерактивна діагностика за симптомами
**Мета:** Допомогти новачку зрозуміти причину нездужання вазона без залучення платних ШІ та без ризику галюцинацій нейромереж.

```
[Старт: клік «Діагностика» з картки рослини або дії «Є проблема»]
                            │
                            ▼
           [Етап 1: Оберіть зону ураження]
           (Листя / Стебло та пагони / Ґрунт та горщик / Шкідники)
                            │ (наприклад, обрано «Листя»)
                            ▼
           [Етап 2: Оберіть конкретний симптом]
           - Жовтіє нижнє листя
           - Сохнуть кінчики листя
           - Листя в'яне та втратило тургор (поникло)
           - Коричневі або чорні плями
                            │ (наприклад, обрано «Листя поникло/в'яне»)
                            ▼
     [Етап 3: Автоматичний аналіз контексту журналу]
     Система перевіряє: коли востаннє відзначався полив для цієї рослини?
                            │
            ┌───────────────┴───────────────┐
            ▼ (Полив був 1–3 дні тому)      ▼ (Полив був > 10 днів тому)

коренів від надлишку води.»            1. Рясно полити до виходу води в піддон;
План дій:                              2. Злити залишки води через 20 хв.
1. Не поливати! Дати просохнути;
2. Перевірити наявність отвору в горщику;

### Flow 4: Перегляд карток знань («Подів-підказок»)
**Мета:** Навчання користувача мікропорціями знань у потрібний момент.

- **Точка входу 1 (Контекстна):** Натискання на значок «💡 Підказка» поруч із кнопкою поливу або перевірки.
- **Точка входу 2 (Профіль рослини):** Горизонтальна карусель карток у верхній частині картки рослини:
  - Картка 1: «Як перевіряти вологість» (візуальна інструкція).
  - Картка 2: «Вимоги до освітлення» (де саме поставити).
  - Картка 3: «Помилка новачка» (чого категорично уникати).
- **Точка входу 3 (Розділ «Довідник»):** Загальні поди для початківців («Що таке дренаж», «Чому не можна поливати холодною водою з-під крана», «Як протирати пил з листя»).

## 3. Стійкість та нетипові сценарії (Edge Cases)

1. **Відмова в дозволі на сповіщення (`POST_NOTIFICATIONS`):**
   - Додаток НЕ блокує роботу і НЕ показує повторних нав'язливих діалогів.
   - На екрані «Сьогодні» з'являється компактний банер: *«Сповіщення вимкнено в системі. Ви можете відстежувати графік догляду тут або увімкнути нагадування в Налаштуваннях»*.
2. **Перезавантаження пристрою / зміна часового поясу:**
   - `WorkManager` оновлює всі заплановані нагадування без дублювання сповіщень.
3. **Рослина без виду («Свій вид»):**
   - Додаток пропонує стандартний універсальний графік перевірки (раз на 7 днів) та показує загальні поди з перевірки ґрунту пальцем.
