## 1. Мета завдання
Спроєктувати користувацькі сценарії (User Flows), інформаційну архітектуру, систему навігації та детальні специфікації екранів для MVP Android-застосунку Flowers. Забезпечити мінімізацію кроків до додавання першої рослини (< 60 с), інтеграцію подів-підказок у контекст догляду, відсутність почуття провини при затримці поливу, обробку відсутності дозволу на сповіщення, підтримку світлої/темної теми та стан порожніх екранів (empty states).

---

## 2. Критерії приймання
- [x] Описано User Flow: швидке додавання рослини (вибір із каталогу або кастомний вид).
- [x] Описано User Flow: щоденний догляд з екрана «Сьогодні» («Виконано», «Відкласти на 1–3 дні», «Пропустити»).
- [x] Описано User Flow: перевірка стану через інтерактивний майстер симптомів.
- [x] Описано структуру екранів (Сьогодні, Мої рослини, Деталі рослини з подами, Майстер діагностики, Журнал «Було/Стало», Довідник, Налаштування).
- [x] Описано порожні стани (Empty States), помилки та запит системного дозволу на сповіщення (`POST_NOTIFICATIONS`).
- [x] Документи оформлено у `docs/design/USER_FLOWS.md` та `docs/design/SCREEN_SPECS.md`.
