# TASK-046 — Точніше розпізнавання помилок ШІ, збій перевірки мережі, тексти безпеки (реліз 1.0, S)

**Джерело:** зауваження QA до виправлення мережі (сесія 017) + рішення Власника 2026-11-20 (INBOX-009, ADR-018).

## Що зроблено
1. `AndroidNetworkChecker.isOnline()` загорнуто в `runCatching` (`checkOnlineSafely`): збій самої перевірки (наприклад, `SecurityException` на частині Android 11) повертає `true`, запит пробується. Справжній офлайн (немає активної мережі / немає VALIDATED) повертає `false`, як і раніше.
2. `AiErrorMapper`: HTTP-коди розпізнаються за **типами** винятків Firebase AI SDK 18.2.0, а не підрядком у тексті будь-якого винятку. Факт з байткоду SDK: HTTP-код у винятку не зберігається; `validateResponse` створює `QuotaExceededException` (у тексті «quota»), `InvalidAPIKey/ServiceDisabled/APINotConfigured/UnsupportedUserLocation`, інакше `ServerException` із сирим текстом сервера. Тому: access-типи → App Check; `QuotaExceededException` → ліміт; `ServerException` → ознаки 403/App Check/PERMISSION_DENIED або 429/RESOURCE_EXHAUSTED (ціле число, не частина довшого), інакше «Сервіс ШІ недоступний». Решта винятків за цифрами/словами не класифікується (→ загальна помилка).
3. Текст таймауту без змін (рішення Власника).
4. UI безпеки (ADR-018): `SafetyNotice(toxic)` замість `AiSafetyNotice`: для UNKNOWN (ШІ-картки й каталог без джерела) і TOXIC показує пораду «Якщо тварина або дитина з'їла частину рослини, негайно зверніться до ветеринара або лікаря. Запишіть назву рослини або сфотографуйте її.», посилання «ASPCA (сайт англійською)» і підказку «Браузер може перекласти сторінку». Показується в каталозі й у деталях рослини. 1.1: ті самі рядки 4 мовами (TASK-034/035).
5. PERMISSIONS.md і Data safety: НЕ змінювались, їх оновлює TASK-021-B (погоджено).

## Тести
73/73 зелені (було 66): мапер на реальних класах SDK (403/429/500/503 лише в `ServerException`; цифри в чужих винятках ігноруються; «read 1500 bytes» не дає «Сервіс ШІ недоступний»; число всередині довшого числа не збігається), `NetworkCheckerTest` (3), тексти безпеки.
