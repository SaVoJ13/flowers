# ОБҐРУНТУВАННЯ СИСТЕМНИХ ДОЗВОЛІВ — FLOWERS (MVP)

- **Проєкт:** Flowers (Android)
- **Етап:** Етап 3 — Архітектура та дозволи (`TASK-006`)
- **Версія:** 1.0 (MVP)

---

## 1. Принцип мінімізації дозволів (Least Privilege)
Застосунок Flowers дотримується суворого принципу найменших привілеїв: запитуються лише ті дозволи, без яких неможливо забезпечити основний сценарій (локальні нагадування), а робота з медіа реалізується без доступу до приватного сховища користувача.

---

## 2. Перелік дозволів у `AndroidManifest.xml`

### 2.1. `android.permission.POST_NOTIFICATIONS`
- **Рівень захисту:** `dangerous` (runtime permission на Android 13+ / API 33+).
- **Навіщо потрібен:** Для надсилання щоденних локальних сповіщень про необхідність перевірити вологість ґрунту вазонів.
- **Обробка відхилення (Graceful Fallback):** Якщо користувач відхиляє запит дозволу, додаток НЕ блокує жодних функцій. Користувач продовжує бачити всі нагадування на головному екрані «Сьогодні».

### 2.2. `android.permission.RECEIVE_BOOT_COMPLETED`
- **Рівень захисту:** `normal` (надається автоматично системою під час встановлення).
- **Навіщо потрібен:** Для відновлення запланованих у `WorkManager` завдань щоденного нагадування після перезавантаження смартфона або оновлення застосунку.

---

## 3. Чому НЕ потрібні дозволи на сховище та галерею?

- **Сучасний Android Photo Picker:** Для вибору фотографій рослини з галереї використовується `androidx.activity.result.contract.ActivityResultContracts.PickVisualMedia`.
- **Переваги для приватності:**
  - `READ_EXTERNAL_STORAGE` — **НЕ потрібен**;
  - `READ_MEDIA_IMAGES` — **НЕ потрібен**;
  - Додаток не має доступу до фотографій користувача в галереї; система передає копію лише того зображення, на яке користувач явно натиснув.

---

## 4. Чому НЕ потрібен дозвіл `INTERNET` у MVP?

- **`android.permission.INTERNET`:** **ВІДСУТНІЙ у MVP збірці**.
- Застосунок працює повністю автономно. Усі дані каталогу, бази подів та дерева симптомів зберігаються всередині APK в `assets/` та локальній SQLite-базі Room.
- Відсутність дозволу `INTERNET` гарантує користувачам повну приватність та 100% захист від витоку персональних даних чи фотографій.
