## 3. Рівень автономії / Autonomy level (конституція 3.4)
- **Рівень / Level:** За замовчуванням діє п. 3.1: агенти самостійно планують, пишуть код, тести, створюють гілки й PR, проводять QA та зливають PR після отримання `QA Verified` від іншого агента і проходження зеленого CI.
- **Посилення для етапів / Phase Gates:** Перехід між етапами (Етап 0 -> 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7) здійснюється **виключно за рішенням Власника (`Owner Approved`)**.
- **Хто може ставити `QA Verified`:** Окремий QA-субагент (автор змін ніколи не верифікує власну роботу згідно з Червоною лінією №9) або безпосередньо Власник.

## 5. Технології й середовище / Technology and environment
- **Стек / Stack:** Kotlin, Jetpack Compose, Material 3, Room (SQLite), WorkManager, Coroutines/Flow, Android Architecture Components.
- **Платформи / Platforms:** Android (орієнтовно minSdk 26, targetSdk 34/35 — фіналізується на Етапі 3).
- **Комп'ютер Власника / Owner's computer:** Windows (10.0.26300), PowerShell, Android SDK (`C:\Users\cocro\AppData\Local\Android\Sdk`), Android Studio (JBR в `C:\Program Files\Android\Android Studio\jbr`).
- **Пристрої для перевірки / Testing devices:** Емулятор Android (AVD) / фізичний пристрій через adb за наявності. За відсутності фізичного пристрою це прямо позначається у звітах як «не перевірено на фізичному пристрої».
- **Підключені модулі / Modules:** Android, локальні сповіщення, локальна база даних Room.
- **Заборонені технології / Restricted:** Платні хмарні сервери, платні ШІ-API, обов'язкова хмарна реєстрація користувачів.

## 10. Посилення й винятки проєкту / Project-specific tightening
1. **$0 серверних витрат:** Додаток працює на 100% локально (Room + WorkManager). Жодних обов'язкових хмарних бекендів і платних ШІ-API.
2. **Нульовий збір персональних даних на старті:** Ніяких обов'язкових акаунтів чи збору контактних даних.
3. **Заборона реальної реклами до Етапу 3:** Жодних бойових ключів чи SDK зі збором даних без схвалення Власника.
4. **Суворе розділення ролей і заборона самоверифікації:** Жоден агент, включаючи Агента 0, не має права верифікувати свій власний код чи документацію.
