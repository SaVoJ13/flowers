## 1. Середовище розробки та інструменти (Windows / Android)
- **[L-001] Шлях до JDK та Android SDK:**
  - *Контекст:* У терміналі PowerShell команда `java` глобально не розпізнається через відсутність у системному `PATH`, але повноцінний JDK (JBR) присутній у складі Android Studio: `C:\Program Files\Android\Android Studio\jbr\bin\java.exe`.
  - *Правило:* Для запуску Gradle CLI або компіляції з терміналу слід використовувати шлях до JBR або передавати `JAVA_HOME="C:\Program Files\Android\Android Studio\jbr"`. Android SDK розташовано у `C:\Users\cocro\AppData\Local\Android\Sdk`.

- **[L-002] Кодування та символи в PowerShell:**
  - *Контекст:* У консолі Windows PowerShell за замовчуванням кодування може спричиняти спотворення кириличних символів при неправильному виклику команд.
  - *Правило:* Використовувати UTF-8 або перевіряти вивід через перенаправлення/нативні інструменти читання.
