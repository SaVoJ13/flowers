# СПЕЦИФІКАЦІЯ ЕКРАНІВ ТА UI-КОМПОНЕНТІВ — FLOWERS (MVP)

- **Проєкт:** Flowers (Android)
- **Етап:** Етап 2 — UX та ботанічний контент (`TASK-003`)
- **Версія:** 1.0 (MVP)
- **Автор:** Агент UX/UI під координацією Агента 0

---

## 1. Загальні принципи дизайну (Design Principles)

1. **Material Design 3 (M3):** Використання стандартних динамічних кольорів, закруглених кутів (16–24 dp), плавних анімацій переходів.
2. **Ботанічна палітра:**
   - Primary: М'який темно-зелений (`#2D5A27` / Dark: `#81C784`).
   - Secondary: Теплий трав'яний / шавлієвий (`#558B2F` / Dark: `#AED581`).
   - Surface/Background: Світлий кремово-бежевий (`#FBFDF7`) / Темний глибокий оливково-сірий (`#1A1C19`).
   - Accent / Warning (для вологості й відкладення): М'який бурштиновий (`#FFA000`).
   - Error / Disease: Стриманий теракотовий (`#D32F2F`).
3. **Екологія уваги (No-Guilt UI):** Прострочені завдання позначаються нейтральним написом «Час оглянути», а не загрозливими червоними банерами та знаками оклику.
4. **Підтримка темної теми:** 100% контрастність за стандартом WCAG AA.

---

## 2. Специфікація основних екранів

### Екран 1: «Сьогодні» (TodayScreen)
- **Призначення:** Головний робочий екран користувача для щоденного огляду завдань.
- **Header:**
  - Назва: «Сьогодні» + поточна дата (наприклад: «Середа, 18 листопада»).
  - Іконка налаштувань (шестірня) у верхньому правому куті.
- **Секція 1: Потребують перевірки сьогодні:**
  - Картки рослин. Кожна картка містить:
    - Фото (або заглушка-іконка виду);
    - Назва рослини та локація («Монстера • Вітальня»);
    - Тип дії: «Перевірка ґрунту (полив)»;
    - Короткий под-підказка: *«Ґрунт має просохнути на 2 см углиб»*;
    - Панель кнопок:
      - Кнопка 1 (Основна): `[✓ Виконано]` (зелена заливка);
      - Кнопка 2: `[⏳ Відкласти]` (відкриває меню: «На 1 день», «На 2 дні», «На 3 дні»);
      - Кнопка 3 (Меню ...): «Пропустити цей цикл», «Перевірити стан / Проблема».
- **Секція 2: Найближчі дні (завтра, післязавтра):**
  - Згорнутий або компактний список рослин, чия черга надійде незабаром.
- **Empty State (Коли всі перевірки виконано):**
  - Ілюстрація щасливої рослини.
  - Текст: *«Усі вазони доглянуті! Наступна перевірка — завтра о 09:00»*.
- **Empty State (Коли ще немає жодної рослини):**
  - Текст: *«У вас ще немає доданих рослин»*.
  - Велика кнопка: `[+ Додати першу рослину]`.

### Екран 2: «Мої рослини» (PlantsListScreen)
- **Призначення:** Огляд усієї домашньої колекції вазонів.
- **Header:** Пошуковий рядок (за назвою) + фільтр-чипи за кімнатами («Усі», «Вітальня», «Спальня», «Кухня»).
- **Список рослин (Сітка 2 колонки або список карток):**
  - Прев'ю фотографії;
  - Власна назва + вид;
  - Статус догляду: бейдж «Зволожена» (зелений) або «Потребує огляду» (бурштиновий);
  - Кількість днів до наступної перевірки.
- **Floating Action Button (FAB):** Велика зелена кнопка `+` у нижньому правому куті для додавання рослини.

---

### Екран 3: «Додавання / Редагування рослини» (AddEditPlantScreen)
- **Форма введення:**
  1. **Фото:** коло по центру для вибору фото (Камера / Галерея) або автоматичний значок виду.
  2. **Власна назва:** текстове поле (наприклад: «Фікус у кабінеті», обов'язкове).
  3. **Вибір виду:** випадаючий список або діалог пошуку по каталогу рослин із можливістю обрати «Інший вид / Немає в списку».
  4. **Локація:** поле вибору кімнати з автопідказками («Вітальня», «Спальня», «Балкон», «Кухня», «Офіс»).
  5. **Освітлення:** перемикач із трьох варіантів (іконки: Тінь / Розсіяне світло / Пряме сонце).
  6. **Нагадування:** перемикач (Toggle) «Увімкнути нагадування» та вибір бажаного інтервалу базової перевірки (за замовчуванням підтягується з обраного виду, наприклад: «Кожні 7 днів»).
- **Кнопка збереження:** `[Зберегти рослину]`.

---

### Екран 4: «Картка рослини» (PlantDetailScreen)
- **Top Bar:** Фото рослини на всю ширину з кнопками «Назад», «Редагувати», «Видалити».
- **Секція 1: Базова інформація:**
  - Назва, ботанічний вид, дата додавання, кімната, рівень світла.
- **Секція 2: Навчальні поди виду (Care Pods Carousel):**
  - Горизонтальний скрол із 3 карток:
    - 💧 *Вологість і ґрунт:* як перевірити стан землі.
    - ☀️ *Освітлення:* де поставити в кімнаті.
    - ⚠️ *Помилка новачка:* головний ризик (наприклад: «Не залишайте воду в піддоні»).
- **Секція 3: Швидкі дії догляду:**
  - `[Полив]`, `[Підживлення]`, `[Пересадка]`, `[Діагностика стану]`.
- **Секція 4: Історія догляду та фотодинаміка:**
  - Хронологічний список подій із нотатками та мініатюрами фотографій «до/після».

---

### Екран 5: «Майстер аналізу стану» (PlantDiagnosisScreen)
- **Крок 1: Локалізація проблеми (Single Choice):**
  - Великі картки з іконками: «Листя», «Стебло і пагони», «Ґрунт і горщик», «Шкідники».
- **Крок 2: Опис симптому (Filtered List):**
  - Список конкретних проявів (наприклад, для листя: «Жовтіють кінчики», «В'яне й поникло», «Сухі коричневі плями»).
- **Крок 3: Результат та кореляція:**
  - Блок «Контекст журналу»: *«Останній полив був учора (17 листопада). Ймовірність переливу: ВИСОКА»*.
  - Блок «Ймовірна причина»: доступне пояснення простою мовою без псевдонаукових термінів.
  - Блок «План дій» (покрокові чекбокси):
    - [ ] Перевірте наявність застійної води в піддоні;
    - [ ] Не поливайте, доки ґрунт не просохне мінімум на 3-4 см;
    - [ ] Забезпечте приплив свіжого повітря без холодного протягу.
  - Кнопка: `[Зберегти в журнал та додати фото]`.

---

### Екран 6: «Довідник та База знань» (CatalogScreen)
- **Header:** Пошук рослин за назвою.
- **Вкладка 1: Популярні рослини:**
  - Список видів із фільтром «Легко для початківців». Клік відкриває паспорт виду та його поди знань.
- **Вкладка 2: Загальні поди новачка:**
  - Статті-підказки: «Як обрати перший горщик», «Золоте правило поливу», «Що таке розсіяне світло».

---

### Екран 7: «Налаштування» (SettingsScreen)
- **Тема оформлення:** Світла / Темна / Системна.
- **Мова:** Українська / English.
- **Сповіщення:**
  - Перемикач сповіщень.
  - Час нагадування (TimePicker, за замовчуванням 09:00).
- **Дані:**
  - «Експорт резервної копії (JSON)»;
  - «Очистити всі дані» (з червоним попередженням).
- **Про додаток:** Версія, ліцензія (Proprietary), інформація про офлайн-роботу.
