## 2. Обсяг робіт
1. **Мережевий дозвіл:** Додати `<uses-permission android:name="android.permission.INTERNET" />` у `AndroidManifest.xml`.
2. **Керування налаштуваннями та підпискою (`UserPreferences`):**
   - Збереження преміум-статусу (`isPremium`) та ключа Gemini API (`geminiApiKey`).
   - Для пристрою Власника преміум-статус увімкнено за замовчуванням.
3. **Сервіс генерації рослин через ШІ (`GeminiPlantService`):**
   - Запит до Google Gemini REST API зі структурованою схемою JSON: назва українською, латинська назва, народна назва, освітлення, інтервал перевірки ґрунту в днях, ґрунт, токсичність для тварин, специфічні поради з поливу та догляду.
   - Збереження згенерованої рослини в локальну таблицю `catalog_plants` та створення картки-поду в `care_pods`.
4. **Інтерфейс користувача (Compose UI):**
   - У `CatalogScreen.kt`: діалог або кнопка `✨ Додати рослину через ШІ`, якщо потрібного виду немає в каталозі.
   - У `AddEditPlantScreen.kt`: швидка генерація з поля ботанічного виду.
   - У `SettingsScreen.kt`: блок налаштувань ШІ (Gemini API ключ, статус підписки Premium).
5. **Тестування:**
   - Модульні тести парсингу відповідей ШІ та валідації діапазонів інтервалів.
6. **Розгортання та QA:**
   - Збірка APK, оновлення на Samsung Galaxy S24 Ultra (`RZCX326349A`).
   - Незалежна верифікація Lead QA Inspector.
