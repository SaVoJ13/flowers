# TASK-054 — Адаптивні нагадування про перевірку ґрунту та спрощення навігації

## Мета

Реалізувати ключовий продуктовий етап Flowers 2.0 (ADR-021):
1. Переорієнтація головного меню на особисті рослини: навігація з трьома розділами («Сьогодні», «Мої рослини», «Опції»). Довідник вилучається з `BottomNavBar` без видалення `catalog_plants`, DAO чи функцій, від яких залежить застосунок.
2. Система адаптивних нагадувань перевірки ґрунту: тексти «Час перевірити ґрунт у [назва рослини]» замість автоматичних наказів полити.
3. Дві дії користувача на екрані «Сьогодні»:
   - «Ґрунт перевірено — Полито»: фіксація `WATER` виключно після явного підтвердження користувачем реального поливу, оновлення `lastWateredDate` та наступної дати перевірки.
   - «Ще вологий — Відкласти на 2 дні»: фіксація `DELAY` без фіктивного поливу (`lastWateredDate` не змінюється), перевірка переноситься рівно на два календарні дні.
4. Адаптація порад до виду: використання полів Room v3 (`speciesName`, `botanicalName`, `wateringAdvice`, `lightLevel`, `checkIntervalDays`, сезонність). Обережні рекомендації за відсутності даних замість жорстких універсальних сантиметрів.
5. 100% збереження даних Room v3: жодних руйнівних змін схеми, цілісність усіх рослин, історії та нагадувань.
6. Повна автономність (Offline-first): перевірка ґрунту, фіксація дій та навігація працюють без інтернету та без Gemini.

1. **Реорганізація навігації:**

   - Оновлення `FlowersNavHost.kt`: `showBottomBar` для 3 розділів; збереження маршруту `Screen.Catalog` у `NavHost` для зворотної сумісності.
   - Оновлення рядкових ресурсів `res/values/strings.xml`.

   - Підтримка новостворених рослин із `lastWateredDate = null` (перевірка призначається на день створення).

   - Безпечний фолбек за відсутності даних.

4. **Сповіщення та перезапуск пристрою:**

6. **Тестування:**
   - Модульні тести `ReminderCalculatorTest`: перевірка розрахунку на межах місяців (січень-лютий, лютий-березень), років (31 грудня - 1 січня) та переходів DST (весняний та осінній переходи).
   - Модульні тести `SoilCheckAdvisorTest`: адаптація до виду, освітлення, сезону, фолбек.
   - Модульні тести `TodayViewModelTest`: дії WATER та DELAY, збереження `lastWateredDate = null`, захист від дублювання.
   - Інструментальні тести на емуляторі (Compose UI тест 3 вкладок навігації та дій перевірки ґрунту).
