# Технічні нотатки для TASK-033 (локалізація) і TASK-037 (каталог v3)

> Підготовлено 2026-11-20 (автономна сесія). **Код 1.1 не чіпаємо до заморозки 1.0.** Це нотатки з уже виконаної роботи; джерело вимог: `RELEASE_1_1_PLAN.md` §4–5, ADR-016, ADR-018.

## TASK-037 — каталог v3, Room, імпортер
1. **Читати JSON тим самим строгим способом, що й валідатор** (`StrictJson` у `app/src/test/.../catalog/CatalogValidator.kt`): без коментарів, одинарних лапок, ключів без лапок; дубль ключа = помилка; BOM відхиляється. Gson за замовчуванням лояльний і мовчки перезаписує дубль ключа: валідатор пропустив би файл, який імпортер прочитав би інакше. Для продакшн-коду використати `JsonReader` зі `Strictness.STRICT` (Gson 2.11 це підтримує) і окремий перевірений шлях для дублів, або винести `StrictJson` з test у main і покрити тестами.
2. **Імпорт не залежить від `count()==0`**: порівнювати `contentVersion` з `content_meta`; торкатися лише `origin=BUILTIN`; ШІ-картки й «Мої рослини» не змінюються. Прибрати подвійний шлях (`PrepopulateCallback` + `ensurePopulated`).
3. **ID стабільні**: 20 наявних ID (`CatalogValidator.LEGACY_IDS`) не змінюються; `retired=true` дозволено лише з `replacedBy` (валідатор забороняє цикли). Імпортер має резолвити `plants.speciesId` після імпорту (тест: усі `speciesId` існуючих рослин резолвляться).
4. **Міграція 2→3 без DROP/DELETE**: новий шаблон тесту міграції вже є (`MigrationTest` на sqlite-jdbc, схеми `app/schemas/.../2.json`); для v3 експортувати `3.json`. Старі колонки (`nameUk`, `light`, `soilType`, `toxicToPets`) лишаються; `toxicToPets` не використовувати для нових карток, джерело істини `safety.pets/children` (TOXIC/NON_TOXIC/UNKNOWN). У UI `UNKNOWN` = нейтральний `SafetyNotice(toxic=false)` (як ШІ-картки), `TOXIC` = попередження; `NON_TOXIC` з джерелом може показувати «за джерелом X не токсична» (текст погодити).
5. **Excerpts не потрапляють у assets** (`docs/content/catalog/drafts/bNN.excerpts.json` лише в репозиторії). У assets лише `manifest.json`, `sources.json`, `bNN.json`; тест `CatalogFiles.scan` відхиляє інші файли.
6. **Одне нормалізування тексту для пошуку й для ключа сигналу попиту** (план §4.6, §7): регістр, апострофи `'`/`’`/`ʼ`, `ґ→г`, `ё→е`, діакритика pl; та сама функція у ViewModel і репозиторії (зараз продубльована; `CatalogSearch` є лише в тестах).
7. **Безпечні рядки** (ADR-018): `AiTexts` (порада «Якщо тварина або дитина з'їла…», «ASPCA (сайт англійською)», «Браузер може перекласти сторінку») переносяться в `strings.xml` 4 мовами (TASK-034/035).
8. **Заборонені символи й гомогліфи** в текстах картки перевіряє валідатор; імпортер додатково не довіряє даним: довжини обрізати не треба (валідатор), але парсинг має бути стійким до відсутніх мов (відкат en → uk).

## TASK-033 — каркас локалізації
1. `MainActivity` (зараз `ComponentActivity`) → `AppCompatActivity`; без цього `AppCompatDelegate.setApplicationLocales` у Compose не працює на API ≤ 32 (ADR-016, не підтверджено повністю документацією для всіх версій: перевірити на емуляторі API 28 і на телефоні Android 13+).
2. `values/` англійська за замовчуванням, `values-uk/-ru/-pl`; `resources.properties` з `unqualifiedResLocale=en`; `generateLocaleConfig = true`.
3. **Налаштування, що зараз суперечать продукту** (TASK-047): картка «Flowers Premium: АКТИВОВАНО» і жорстко прописане «Версія: 1.1.0» у `SettingsScreen.kt`; текст «Приватність та безпека» згадує фото. Це слід вичистити ДО перенесення рядків у ресурси (інакше переклади закріплять помилки).
4. Рядки поза Activity (`NotificationHelper`, `DailyReminderWorker`): через локалізований контекст (`ContextCompat`/`createConfigurationContext` з мовою застосунку); перевірити, що канал сповіщень оновлює назву.
5. Текстові константи, що тестуються (`AiTexts`, `ReportTexts`, `AiErrorMapper.MSG_*`): тести порівнюють дослівні українські рядки; при переході на ресурси потрібен тест із `Resources`/Robolectric або винесення в чисті функції з параметром мови (Robolectric у проєкті немає, додавання залежності потребує запису в `THIRD_PARTY.md`).
6. Скарга (TASK-027) надсилає `responseText` та `plantQuery` мовою, у якій згенеровано картку; правила Firestore не залежать від мови (довжина в UTF-16 одиницях, емодзі враховуються як 2).
7. `allowBackup=true`: після зміни мови/ресурсів нічого не ламається; рішення про вимкнення резервного копіювання лишається за Власником (INBOX-010 п.5).
