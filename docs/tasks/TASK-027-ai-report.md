# TASK-027 — Кнопка «Поскаржитися на відповідь ШІ» (реліз 1.0)

**Рішення:** O-Q3 (ADR-014, залежність `firebase-firestore`, збір скарг), O-Q6 (12 міс.), ADR-018 (сигнал попиту сюди НЕ входить, він у 1.1 TASK-044).

## Зроблено (код і правила)
- `firestore.rules`: `reports/{id}` лише `create` з жорстким форматом (поля `feature`, `plantQuery`≤100, `responseText`≤4000, `reason` ∈ wrong/dangerous/offensive/other, `comment`≤500 необов'язковий, `appVersion`≤32, `createdAt == request.time`, `expireAt` ≈ +365 дн.); `read/update/delete` заборонені; усе інше закрито. `firebase.json` посилається на файл.
- Тести правил в емуляторі: `firestore-rules-test/` (`npm install && npm test`, Node 18+, Java 21+): 14/14 (негативні: зайве поле, довжини, порожні, типи, невідома причина, час, expireAt, читання/оновлення/видалення, інші колекції).
- Застосунок: `AiReport` (межі дзеркалять правила; тест звіряє з файлом правил), `AiReportRepository` (без мережі не пише; таймаут 15 с; збій → повідомлення), `FirestoreReportSink`, `AiReportButton` (діалог: причина, коментар, підтвердження «Дякуємо», не виводить із застосунку), показ на ШІ-картках у каталозі й деталях рослини. Залежність `firebase-firestore` (версія з BoM) у `docs/THIRD_PARTY.md`.
- Поле `plantQuery` містить назву рослини з картки (`nameUk`), не введений користувачем текст. Фото й ідентифікатори не збираються.
- Дії Власника: `docs/tasks/TASK-027-owner-firestore-guide.md` (створення бази, регіон eur3, правила, TTL, App Check).

## Відомі обмеження (з QA, `QA Verified`)
- Якщо мережа «є», але зв'язку фактично немає, Firestore ставить запис у локальну чергу: користувач бачить «Не вдалося» через 15 с, а запис може піти пізніше (при повторі можливий дубль; запис старший за ~5 днів відхилить `expireAt`). Прийнято для 1.0.
- `expireAt` рахується за годинником пристрою (розбіжність > ~5 днів = відхилення).
- Рядки з самих пробілів правила пропускають (застосунок обрізає пробіли сам).
- R8 у release вимкнений (`isMinifyEnabled=false`); перевірити при ввімкненні в TASK-021-C.

## Не перевірено
Без бази Firestore наскрізна перевірка «скарга з'явилась у консолі» неможлива (чекає кроків Власника). Екран на телефоні: пристрій був заблокований PIN. Політика/Data safety/PERMISSIONS не змінені (TASK-021-B).
