# TASK-025 — Токсичність не з генерації ШІ; Room v2

- **Статус:** Реалізовано, очікує незалежної QA й перевірки на телефоні (PR `feat/task-025-no-ai-toxicity`, стек поверх TASK-026).
- **Джерело:** `docs/release/RELEASE_1_0_PLAN.md` §2.2; ADR-014 (O-Q5).
- **Обсяг:**
  1. Промпт винесено в `AiPrompt`; `toxic_to_pets` прибрано з промпту й DTO `GeneratedPlantResponse`; у промпті є заборона згадувати безпеку для тварин/дітей.
  2. `CatalogPlantEntity.isAiGenerated` (нова колонка, `DEFAULT 0`). Для ШІ-карток `toxicToPets` не використовується; UI показує нейтральний текст «Безпека для тварин і дітей не перевірена. Уточніть у ветеринара або в довіднику ASPCA» з кнопкою-посиланням на довідник ASPCA (у Довіднику й над подами ШІ-рослини в деталях). Для рослин каталогу лишається перевірене попередження.
  3. **Room версія 2, явна міграція** `Migrations.MIGRATION_1_2` (`ALTER TABLE ADD COLUMN` + `UPDATE ... WHERE id LIKE 'ai\_%' ESCAPE '\'`). Обрано варіант без перестворення таблиць: жодних DROP/DELETE, тож `plants` і `care_events` (FK на `plants`, CASCADE) не зачіпаються. Старі ШІ-картки позначаються `isAiGenerated = 1`, їхній ШІ-прапорець токсичності скидається.
  4. `exportSchema = true`, схему v2 збережено в `app/schemas/`. Тести: `MigrationTest` (7, sqlite-jdbc на JVM, звірка з експортованою схемою), `AiPromptTest` (2), каталог 16 true / 4 false.
- **Нова залежність (лише test scope):** `org.xerial:sqlite-jdbc:3.46.1.3`, Apache-2.0 (перевірено в POM), записано в `docs/THIRD_PARTY.md`.

## Перевірка прапорців каталогу (план §2.2 п. 4)
У `PLANT_CATALOG.json` 20 рослин: 16 `true`, 4 `false` (chlorophytum, peperomia, maranta, calathea); число підтверджено тестом. **Звірку з первинним джерелом по кожній рослині не виконано:** `docs/content/SOURCES.md` називає Missouri Botanical Garden загалом (рядки 29-32), посилань на сторінки окремих видів немає. Розбіжності не виявлено лише у вигляді загальної відповідності відомим переліком (не є доказом). Рекомендація: QA або Власник вибірково перевіряє види за Missouri Botanical Garden; за потреби додати посилання по видах у SOURCES.md.
